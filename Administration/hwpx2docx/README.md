# hwpx → docx 변환기 (GMC 주보 양식)

한글(HWPX) 주보를 Word(docx)로 옮기는 스크립트입니다. HWPX 안의 XML을 직접 읽어 Word 형식으로 다시 쓰기 때문에
LibreOffice·한컴 프로그램 없이 `lxml`만 있으면 동작합니다.

```bash
pip install lxml
python3 hwpx2docx.py "주보.hwpx" -o "주보.docx"
```

| 옵션 | 설명 |
|---|---|
| `--slack 300` | 쪽 위·아래 여백에서 덜어 내는 여유(twip, 1/1440인치). 기본 300(약 0.21인치). 한글과 Word의 글꼴 차이로 단이 넘쳐 3쪽이 되면 값을 키우고, 여유가 충분하면 줄이면 됩니다. |
| `--flexible-rows` | 최상위 표의 행 높이를 '최소 높이'로 둡니다. 글이 늘면 행이 커지지만 쪽/단이 넘칠 수 있습니다. 기본은 한글처럼 고정 높이입니다. |

`sample/` 에 2026-10-04 주보를 변환한 결과(`주보_2026-10-04.docx`)와 LibreOffice 렌더링 미리보기가 있습니다.
미리보기는 한컴·맑은 고딕 글꼴이 없는 환경에서 대체 글꼴로 그린 것이므로 글꼴 모양은 실제와 다릅니다.

## 변환 규칙

| 한글(HWPX) | Word(docx) |
|---|---|
| 단위 HWPUNIT(1/7200인치) | twip(1/1440인치) = ÷5 |
| 가로 용지, 여백, 2단(단 간격) | 동일하게 설정 |
| 글자 모양(글꼴, 크기, 굵게, 기울임, 색, 장평, 자간, 밑줄, 음영) | 글자 서식 |
| 문단 모양(정렬, 들여쓰기, 문단 위·아래 간격, 탭 정지점, 글자 단위 줄바꿈) | 문단 서식 |
| 줄 간격(글자 크기 × %) | 고정 줄 높이. 줄 위치(`lineseg`)를 읽어 한글과 같은 줄 피치로 환산 |
| 단 나눔(자동) | 줄의 세로 위치가 되돌아가는 지점에 '단 나누기' 삽입 |
| 표(병합 셀, 셀 폭/높이/여백, 테두리, 배경색, 세로 정렬) | 표 |
| 글상자 | 1×1 표(테두리·배경 포함) |
| 그림(QR 코드) | 인라인 그림 |

## 알려진 차이와 한계 (2026-10-04 주보 기준)

- **글꼴**: Word에 한컴바탕·나눔고딕·맑은 고딕 등 원본 글꼴이 설치되어 있어야 줄바꿈이 한글과 같습니다.
  글꼴이 다르면 줄이 더 늘어나 단이 넘칠 수 있습니다. 그럴 때는 `--slack` 값을 키워 다시 변환하십시오.
- **둥근 모서리**: 한글의 둥근 사각형 글상자는 Word 표로 옮기며 모서리가 직각이 됩니다.
- **겹친 줄**: 한글에서 줄 간격을 극단적으로 줄여 한 줄 위에 겹쳐 놓은 글자(예: 순서표의 `Prayer` 줄과 `3부: 이선민 목자`)는
  Word에서 글자가 잘리므로 겹치지 않게 펴서 옮깁니다. 해당 줄이 한 줄 아래로 내려가며 아래 항목의 위치는 유지됩니다.
- **행 높이 고정**: 기본은 한글과 같은 고정 높이입니다. 표 안 글이 한 줄 이상 늘어나면 잘려 보이므로
  내용을 늘릴 때는 해당 행 높이를 Word에서 조정하십시오.
- 머리글/꼬리말, 각주, 도형(선·타원 등), 수식, 다중 구역은 이 주보에 없어 구현하지 않았습니다. 다른 양식에서는 확인이 필요합니다.
- LibreOffice와 python-docx로 열림을 확인했습니다. 실제 Microsoft Word에서의 열림과 쪽 수는 한 번 확인해 주십시오.
